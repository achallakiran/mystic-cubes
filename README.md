# Mystic Cubes

A zen 3D cube word-search. Turn the cube (drag it, or use the ring dot and tilt arc), find hidden words along straight and slanted lines that can wrap across edges, and reveal an old saying word by word. Unlocked sayings are saved as cards you can replay.

Play: https://achallakiran.github.io/mystic-cubes/

Plain HTML/JS, no build step. `node tests/test.js` checks the generator.
